## Files

- `styles.css`

## Deploy with GitHub Pages

You can use this template in any GitHub repository.

If the GitHub username is `david`, create:

`david.github.io`

Otherwise, create a repository named:

`<your-github-username>.github.io`

Then upload `index.html` and `styles.css` to the repository root.

If Pages is not enabled automatically:

1. Open **Settings**
2. Open **Pages**
3. Select **Deploy from a branch**
4. Choose `main`
5. Choose `/ (root)`
